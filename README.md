# Harness 错误启发

面向个人开发者的 Codex 技能：保护项目主线，区分临时恢复与根因修复，用第一性原理反问和按风险触发的对抗性审查，选择最小充分验证并在证据充分后停止。

## 使用

将本仓库放入 Codex 的用户技能目录，文件夹名为 `harness-error-enlight`。在后续会话中可显式调用：

> 使用 $harness-error-enlight 分析当前问题，判断处理优先级、恢复状态和必要验证。

默认允许自动发现；实际加载取决于宿主。技能是行为指导，不是强制门禁或后台监控。

## 内容

- `SKILL.md`：问题分级、排查、反问、验证与经验沉淀。
- `references/adversarial-review.md`：按风险触发的有限审查。
- `references/behavior-cases.md`：六个行为验证场景。
- `references/sources.md`：改造来源与 MIT 许可声明。

沿用项目现有 Harness 文件，不创建第二套错误数据库。记录错误不等于必须立即治理，延期不等于已解决。项目规则和用户授权仍决定真实操作范围。
